# NimbusShield: 대한민국 날씨 에이전트 커맨드 센터

NimbusShield는 지정된 대한민국 지역의 날씨와 해수면 온도를 모니터링하기 위해 자율형 "날씨 에이전트"를 배치하고 관리할 수 있는 다크 테마 독립형 웹 대시보드 애플리케이션입니다.

블로그 개발기: [NimbusShield: 대한민국 날씨 에이전트 커맨드 센터 개발기](https://velog.io/@ddukddi/xmhbkurj)

## 🚀 시작하기

### 🐳 Docker로 실행하기 (추천 - 6543 포트)
도커 컨테이너를 빌드하고 실행하여 **6543** 포트로 대시보드에 접속할 수 있습니다:

1. **도커 이미지 빌드**:
   ```bash
   docker build -t weather-tracker .
   ```

2. **도커 컨테이너 실행**:
   ```bash
   docker run -d -p 6543:6543 --name weather-sentry weather-tracker
   ```

3. **대시보드 접속 주소**:
   - [http://localhost:6543](http://localhost:6543)

---

### 🐍 로컬 Python 서버로 실행하기 (8080 포트)
수동으로 파이썬 웹 서버를 띄워 테스트하려면 아래 명령어를 사용하세요:
```bash
python3 -m http.server 8080
```
- **파이썬 서버 대시보드 주소**: [http://localhost:8080](http://localhost:8080)

## ⚡ 주요 기능

### 1. 대한민국 지역 및 수동 좌표 지원
* **대한민국 전용 서비스입니다.** 국내 지역 검색 결과만 제공하며, 검색이 어려울 경우 원하는 위치의 `위도, 경도` 포맷(예: `37.217, 126.275`) 및 사용자 지정 이름을 직접 입력해 에이전트를 배치할 수 있습니다.
* 수동 좌표 역시 대한민국 경계(**위도 33~39, 경도 124~132**) 안의 값만 허용되며, 범위를 벗어난 좌표는 등록이 거부됩니다.

### 2. 특정 예보 날짜 탐색
* 실시간 날씨 대신 사용자가 원하는 미래 날짜(최대 16일 이내)의 일일 예보 데이터를 수집해 공기 온도(최저~최고), 일일 강수량, 최대 풍속, 해수면 온도 평균 수치를 한눈에 보여줍니다.

### 3. 직관적인 상태 지시등 및 기상 수치
* 에이전트 카드의 모니터링 상태를 심플한 지시등(🟢 Active / 🔴 Paused / 🟡 Telemetry offline)으로 보여줍니다. API 통신 장애나 서비스 이상이 감지되면 자동으로 노란색 경고등이 점등됩니다.
* 풍속 단위는 국제 표준인 `m/s`로 출력되며, 해수면 온도는 Marine API의 시간별 데이터를 평균하여 보여줍니다.
* **해양 텔레메트리 확장**: 해안/바다 지역인 경우 평균 해수면 온도(SST), 유의 파고(Wave Height), 평균 파주기 및 파향(Wave Period & Direction)을 담은 해양 전용 패널이 동적으로 레이아웃에 추가됩니다. (내륙 지역은 자동 숨김)

### 4. 📈 시간별 예보 그래프 시각화 (Hourly Forecast Charting)
* 에이전트 카드의 차트 아이콘을 누르면 하루 24시간 동안의 시간대별 기온 변화(Temp), 풍속(Wind), 유의 파고(Wave Height) 추이를 다중 Y축(Dual/Triple Y-axes) 기반의 아름다운 neon 꺾은선 그래프(Chart.js)로 즉시 모니터링할 수 있습니다.
* 새로운 차트가 열리면 이전에 열린 다른 차트는 자동으로 소멸되어 브라우저 메모리 누수를 원천 방지합니다.

### 5. ⚔️ 날씨 샌드박스 시뮬레이터 (Weather Sandbox Simulator)
* 우측 사이드바의 샌드박스 패널을 통해 "Enable Override"를 켜면 가상 기상 상황 시뮬레이션 모드가 동작합니다.
* 특정 에이전트 또는 모든 에이전트를 타겟으로 설정하고 슬라이더를 드래그하여 기온, 풍속, 강우량, 해수면 온도, 파고 수치를 실시간으로 덮어쓸 수 있습니다.
* 가상 오버라이드가 진행되는 카드에는 neon `SIM` 배지가 표시되어 직관성을 높이며, 언제든 "Reset" 버튼을 클릭해 실시간 실제 기상청 데이터로 초기화할 수 있습니다.

### 6. 🔔 브라우저 알림 및 Slack/Discord 웹훅 연동 (Alerts & Integrations)
* 우측 사이드바의 **Alert & Integration Settings** 패널을 통해 브라우저 알림 및 Webhook 연동을 제어합니다.
* **Browser Push Alerts**: 브라우저 Push Notification API 권한을 획득하여, 30분 단위 백그라운드 체크 혹은 샌드박스 가상 값 오버라이드 시 기상 경보 임계치를 초과할 때 브라우저 팝업 알림을 띄웁니다.
* **Slack/Discord Webhook**: 사용자의 개인 슬랙이나 디스코드 채널의 Webhook URL을 입력하고 연동하여, 날씨 위반(또는 정상 회복) 이벤트를 해당 메신저 방에 실시간 마크다운 메시지로 전송합니다.
* **Test Send**: 연동된 메신저 방이 올바르게 구성되어 작동하는지 테스트 웹훅을 즉시 보낼 수 있습니다.
* **기상 경보 임계치 기준 (Warning Thresholds)**:
  - 🌡️ 폭염 (Heatwave): &ge; 35.0°C
  - 🥶 한파 (Coldwave): &le; -12.0°C
  - 💨 강풍 (Strong Wind): &ge; 12.0 m/s
  - 🌧️ 호우 (Heavy Rain): &ge; 20.0 mm
  - 🌊 풍랑 (High Waves): &ge; 3.0 m (해양 전용)

### 7. 📅 과거 기상 비교 및 대조 (Historical Weather Comparison)
* **개별 에이전트 대조**: 에이전트 카드의 기록 아이콘(시계 모양)을 클릭하여 **동적 온디맨드(Lazy loading)** 방식으로 과거 1~3년 전 동일 날짜의 실제 날씨 기록을 조회하여 현재 예보값과 대조합니다.
* **전체 에이전트 일괄 대조 (Compare with History)**: 상단 헤더의 `Compare with History` 버튼을 클릭하여 현재 등록된 모든 에이전트의 위치에 대해 지정된 과거 연도(1~3년 전)의 기상 데이터(최고/최저 기온, 최대 풍속, 강수량)를 일괄 수집하고, 현재 예보값 대비 차이(Delta)를 하나의 테이블 뷰로 통합하여 한눈에 파악합니다.
* **Archive API 및 스마트 캐싱**: Open-Meteo Historical Weather Archive API와 비동기 병렬 통신하여 실시간 데이터를 취득하며, 한번 가져온 이력 데이터는 메모리에 안전하게 캐싱되어 중복 네트워크 비용을 차단합니다.

### 8. 에이전트 코네임 이름 변경 (Rename)
* 카드 상단의 편집 아이콘을 누르면 에이전트의 코네임을 즉시 변경할 수 있어 효율적인 에이전트 관리가 가능합니다.

### 9. 🗺️ 그리드 / 지도 듀얼 뷰 (Leaflet Map View)
* 에이전트 목록 상단의 `Grid` / `Map` 토글로 카드 그리드와 지도 뷰를 전환합니다. 지도는 최초 전환 시점에 지연 초기화(Lazy init)되어 초기 로딩 비용을 발생시키지 않습니다.
* CartoDB Dark Matter 타일을 사용해 대시보드의 다크 테마와 톤을 맞췄으며, 각 에이전트는 상태에 따른 원형 마커로 표시되고 팝업에서 기온(최저~최고), 풍속, 강수량을 바로 확인할 수 있습니다.
* `All / Active / Paused` 필터와 연동되어, 현재 필터에 해당하는 에이전트만 마커로 그려지고 지도 배율도 해당 지점들에 맞춰 자동으로 맞춰집니다(fit bounds).

### 10. 📤 CSV 기상 리포트 내보내기 (Weather Report Export)
* **개별 에이전트 상세 리포트**: 카드의 내보내기 아이콘을 클릭하면 해당 에이전트의 메타데이터(ID, 코드네임, 좌표, 대상 날짜, 상태, 마지막 동기화), 현재 예보 수치, 해양 텔레메트리, 과거 기상 비교 기록, 24시간 시간별 예보가 섹션별로 구분된 CSV 파일(`nimbusshield_report_<코드네임>_<날짜>.csv`)로 저장됩니다.
* **전체 요약 리포트**: 헤더의 `Export All` 버튼으로 배포된 모든 에이전트의 핵심 지표를 한 행씩 담은 요약 CSV(`nimbusshield_all_agents_<오늘날짜>.csv`)를 내려받습니다.
* **Excel 한글 호환**: 파일 선두에 UTF-8 BOM을 삽입해 Excel에서 한글이 깨지지 않으며, 쉼표·따옴표가 포함된 지역명·코드네임은 자동으로 이스케이프 처리됩니다.

### 11. 30분 단위 자동 동기화 및 실시간 수동 동기화
* **자동 동기화**: 30분(1,800,000ms)마다 모든 활성 에이전트의 날씨 데이터를 자동으로 백그라운드 스위핑하여 갱신합니다.
* **수동 동기화**:
  * **전체 동기화**: 헤더의 `Sync Agents` 버튼을 통해 구동 중인 모든 활성 에이전트 갱신.
  * **개별 동기화**: 각 에이전트 카드 내의 `↻` 아이콘을 클릭하여 실시간 단독 갱신 (진행 중 회전 애니메이션 동작).
