# NimbusShield: 대한민국 날씨 에이전트 커맨드 센터

NimbusShield는 지정된 대한민국 지역의 날씨와 해수면 온도를 모니터링하기 위해 자율형 "날씨 에이전트"를 배치하고 관리할 수 있는 다크 테마 독립형 웹 대시보드 애플리케이션입니다.

## 🚀 시작하기

### 🐳 Docker로 실행하기 (추천 - 6543 포트)
도커 컨테이너를 빌드하고 실행하여 **6543** 포트로 대시보드에 접속할 수 있습니다:

1. **도커 이미지 빌드**:
   ```bash
   docker build -t weather-tracker .
   ```

2. **도커 컨테이너 실행**:
   ```bash
   docker run -d -p 6543:6543 --name weather-sentry weather-tracker
   ```

3. **대시보드 접속 주소**:
   - [http://localhost:6543](http://localhost:6543)

---

### 🐍 로컬 Python 서버로 실행하기 (8080 포트)
수동으로 파이썬 웹 서버를 띄워 테스트하려면 아래 명령어를 사용하세요:
```bash
python3 -m http.server 8080
```
- **파이썬 서버 대시보드 주소**: [http://localhost:8080](http://localhost:8080)

## ⚡ 주요 기능

### 1. 대한민국 지역 및 수동 좌표 지원
* 국내 지역 검색 결과만 제공하며, 검색이 어려울 경우 원하는 위치의 `위도, 경도` 포맷(예: `37.217, 126.275`) 및 사용자 지정 이름을 직접 입력해 임의의 위치에 에이전트를 배치할 수 있습니다.

### 2. 특정 예보 날짜 탐색
* 실시간 날씨 대신 사용자가 원하는 미래 날짜(최대 16일 이내)의 일일 예보 데이터를 수집해 공기 온도(최저~최고), 일일 강수량, 최대 풍속, 해수면 온도 평균 수치를 한눈에 보여줍니다.

### 3. 직관적인 상태 지시등 및 기상 수치
* 에이전트 카드의 모니터링 상태를 심플한 지시등(🟢 Active / 🔴 Paused)으로 보여줍니다.
* 풍속 단위는 국제 표준에 맞춰 `m/s`로 출력되며, 해수면 온도는 Marine API의 시간별 데이터를 병합하여 평균값으로 보여줍니다.

### 4. 에이전트 코네임 이름 변경 (Rename)
* 카드 상단의 편집 아이콘을 누르면 에이전트의 코네임을 즉시 변경할 수 있어 효율적인 에이전트 관리가 가능합니다.

### 5. 30분 단위 자동 동기화 및 실시간 수동 동기화
* **자동 동기화**: 30분(1,800,000ms)마다 모든 활성 에이전트의 날씨 데이터를 자동으로 백그라운드 스위핑하여 갱신합니다.
* **수동 동기화**:
  * **전체 동기화**: 헤더의 `Sync Agents` 버튼을 통해 구동 중인 모든 활성 에이전트 갱신.
  * **개별 동기화**: 각 에이전트 카드 내의 `↻` 아이콘을 클릭하여 실시간 단독 갱신 (진행 중 회전 애니메이션 동작).
